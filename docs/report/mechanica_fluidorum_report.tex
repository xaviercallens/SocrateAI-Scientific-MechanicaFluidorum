\begin{abstract}
\noindent
This report documents the state of a staged, verifier-in-the-loop research programme on the
global regularity of the three-dimensional incompressible Navier--Stokes equations (NSE),
organised around \emph{Hypothesis U} --- a uniform-in-cutoff enstrophy bound for the
frequency-truncated system. The programme's distinguishing feature is not a claimed proof but
a \emph{method}: every assertion carries an explicit epistemic tier, mechanically enforced by
a two-gate verification pipeline (exact rational arithmetic; Lean~4 kernel compilation with a
pinned axiom footprint). We report 72 theorems kernel-compiled across seven Lean files --- of
which 65 carry Tier~A claims, the remaining 7 having been \emph{demoted} to Tier~C by the
audit below --- six exact-arithmetic certification harnesses, and, equally importantly, a
documented record of what has \emph{failed}: two abandoned numerical designs, five caught
errata (one in a formula sourced from the literature, one in the programme's own design memo,
one a broken commit, one a false positive in the verification gate itself, and one an
unpinned dependency that would have verified the programme against the wrong prover library),
four analytical tracks that remain correctly blocked on undefined objects, and --- the largest
single failure in the programme's history --- \textbf{an external expert audit that killed this
report's own central framing claim} (\S\ref{sec:problem}).
\textbf{The retraction is stated in full and accepted without qualification}: the
formalisation, with a one-dimensional index cutoff, does not restate the unreduced
three-dimensional problem; it describes a dyadic shell hierarchy. The programme has been
re-targeted accordingly, and its formal object is now the truncated viscous Katz--Pavlovi\'c
dyadic shell model. \textbf{No claim is made that Hypothesis U is true, in any form, nor that
the Navier--Stokes problem is resolved.} The Millennium Prize problem remains open and is not
addressed by anything proven here.
\end{abstract}

\subsection{The epistemic charter}

The organising principle, stated in \texttt{SPEC.md} \S0, is a division of labour:

\begin{center}
\emph{The machine verifier checks the proofs; the human mathematician audits the questions.}
\end{center}

Machine verification establishes that a proof is valid. It cannot establish that a
\emph{statement} means what the mathematics intends --- that a formalisation is
\emph{adequate} to its informal gloss. Adequacy is reserved to human audit. Consequently
\textbf{no LLM output gates a tier promotion}, and several artifacts in this repository are
compiled, kernel-clean, and nonetheless explicitly marked \textsc{draft} pending human
statement-adequacy audit (\S\ref{sec:audit}).

\begin{keybox}{A latent reproducibility defect, found by doing the cold build}
\texttt{lean\_src/} was made a standalone Lake project on 2026-08-13, so Gate 2 no longer

not hypothetical: an unrelated build running in that shared checkout rebuilt its \texttt{.olean}

project's \texttt{lakefile} declared its dependency as \texttt{require mathlib from git} with

\emph{master} --- which in general does not build against the pinned toolchain, and, worse,
would have silently verified every result against a \emph{different Mathlib} than the one all
existing \texttt{LEDGER.md} claims were checked with. For a programme whose entire epistemic
claim rests on machine-checkability, an unpinned verifier is a defect in the foundation, not in
the build script. Mathlib is now pinned by revision, and the lockfile pinning every transitive
dependency is tracked rather than ignored.
\end{keybox}

\section{The Problem, Stated Honestly}
\label{sec:problem}
%==============================================================================

\subsection{Classical setting}

The incompressible Navier--Stokes equations on the torus $\T^3$ are
\begin{equation}
\partial_t u + (u\cdot\nabla)u = -\nabla p + \nu\Delta u,
\qquad \nabla\cdot u = 0,
\qquad u(0)=u_0 .
\label{eq:nse}
\end{equation}
Leray established global existence of weak solutions \cite{leray1934}. The Clay Millennium
Prize problem, as formalised by Fefferman \cite{fefferman-clay}, asks for a proof of
\emph{exactly one} of four statements --- (A) existence and smoothness on $\R^3$;
(B) existence and smoothness on $\R^3/\Z^3$ (the periodic case, which is the setting of this
programme); (C) breakdown on $\R^3$; (D) breakdown on $\R^3/\Z^3$. Note that a
\emph{breakdown} result resolves the problem just as a regularity result does; this is
consistent with the present programme's stance that a negative verdict is a successful
outcome. The obstruction is \emph{supercriticality}: the natural energy bound is too weak to
control the nonlinearity at small scales.

\subsection{The regularised family and Hypothesis U}

For $\alpha'>0$ let $J_{\sqrt{\alpha'}}$ denote the projection onto Fourier modes
$|k|\le 1/\sqrt{\alpha'}$, and let $u^{(\alpha')}$ solve the truncated system
\begin{equation}
\partial_t u + \bigl((J_{\sqrt{\alpha'}}u)\cdot\nabla\bigr)u = -\nabla p + \nu\Delta u,
\qquad \nabla\cdot u=0,\qquad u(0)=J_{\sqrt{\alpha'}}u_0 ,
\label{eq:truncated}
\end{equation}
which is globally smooth for each fixed $\alpha'>0$.

\begin{hypothesis}[Hypothesis U]
For data $u_0$ and horizon $T$,
\begin{equation}
\sup_{\alpha'>0}\ \sup_{0\le t\le T}\ \bigl\|\nabla u^{(\alpha')}(t)\bigr\|_{L^2(\T^3)} < \infty .
\label{eq:hypU}
\end{equation}
\end{hypothesis}

\begin{proposition}[Millennium Reformulation; \tC{} at paper level]
If Hypothesis U holds for all smooth divergence-free $u_0$ and all $T$, then 3D
Navier--Stokes is globally regular. The chain is: energy identity $\Rightarrow$
$L^\infty_tL^2_x\cap L^2_tH^1_x$ bounds $\Rightarrow$ Aubin--Lions compactness $\Rightarrow$
a strong-$L^2$ subsequential limit which is Leray--Hopf $\Rightarrow$ under U the limit lies
in $L^\infty_tH^1_x\hookrightarrow L^\infty_tL^6_x$ $\Rightarrow$ the Serrin class
$2/s+3/q=1/2\le1$ $\Rightarrow$ smooth \cite{prodi-serrin-modern}.
\end{proposition}

\begin{warnbox}{Retraction --- please read before any other claim in this report}
\textbf{An earlier version of this report carried, in this box, the claim that
``Hypothesis~U is a restatement of the open core of the Millennium problem, not a reduction of
its difficulty''. That claim was submitted to external expert audit on 13~August 2026 and was
\textsc{killed} (verdict D1). It is retracted here in full.}

The retraction is not that the claim was too strong about \emph{difficulty} --- it is that the
claim was false about \emph{what had been formalised}. The audit found that the programme's
Lean statements are indexed by a one-dimensional shell index $n\in\N$ rather than a
frequency $k\in\Z^3$ (verdict A2: the index flattening destroys the lattice geometry, the
density of states, and the triad constraint $k_1+k_2=k_3$); that the enstrophy weight was the
exponential sequence $4^n$ rather than the Laplacian symbol $|k|^2$ (A3); and that the
mode-interaction term $B$ was an \emph{unconstrained} parameter, so that certifying a bound
for it was, in the auditor's words, ``authenticating a mathematically empty envelope'' (A5).
Taken together, what the formalisation describes is a \textbf{dyadic shell hierarchy}, not the
unreduced 3-D equations. The prose of \eqref{eq:nse}--\eqref{eq:hypU} above was never wrong;
the claim that the \emph{formal artifacts} restated it was.

\textbf{The new target.} The owner accepted the verdict in full (\texttt{docs/Memo 1.md}) and
re-targeted the programme rather than defending the framing. The formal target is now
\textbf{global regularity bounds for the truncated viscous Katz--Pavlovi\'c dyadic shell
model} --- not a proxy for the 3-D problem, but an object of study in its own right, and a
respected active area of mathematical fluid mechanics (blow-up: Katz--Pavlovi\'c
\cite{katz-pavlovic}, Cheskidov \cite{cheskidov}; regularity under strong dissipation:
Barbato--Morandin--Romito \cite{barbato-morandin-romito}). A machine-verified
regularity-or-blow-up theorem for that model would, to the authors' knowledge, be a first. The
3-D bridge --- the $\Z^3$ reindexing, OP-2 and OP-6 (\S\ref{sec:opsix}) --- is explicit, open
future work, and is never again to be an implicit claim of the formalisation.

\textbf{Why this is recorded as a success of the method and not merely as a setback.} This
programme's Definition of Done (\S\ref{sec:summary}) does not include proving Hypothesis~U. It
includes obtaining human verdicts \emph{whatever they are}. The tier system exists precisely so
that a framing claim can be located, isolated, and killed without taking any kernel-verified
theorem down with it --- and that is what happened: every Lean file still compiles, and the
retraction cost exactly the seven theorems that deserved to be demoted (\S\ref{sec:audit}).
The full verdict table (A1--A5, B1--B5, C1, D1--D2) with dispositions is in \texttt{LEDGER.md};
the retraction text is normative in \texttt{SPEC.md}~\S1.2.
\end{warnbox}

\begin{keybox}{What survives the retraction, stated precisely}
Hypothesis~U \eqref{eq:hypU} as an informal statement about the continuum truncated system, and
Proposition~5.1 as paper-level mathematics, are unaffected --- they were always \tC{} at paper
level and are so labelled above. What is retracted is the assertion that the \emph{Lean
formalisation} of \S\ref{sec:audit} is a formalisation of \emph{that} statement. Audit verdicts
A1 (the quantifier order $\exists C\,\forall N$) and A4 (quantifying over every solution) were
upheld, so the statement's \emph{logical shape} was sound; it was its \emph{referent} that was
wrong. Under the pivot, A2 and A3 dissolve rather than being repaired: for the dyadic shell
model the index \emph{is} the object and the weight $4^n=k_n^2$ \emph{is} the correct weight.
A5 was repaired by instantiating $B$ (\S\ref{sec:audit}).
\end{keybox}

\section{Dual-Scale Geometry and T-Duality}
\label{sec:tdual}
%==============================================================================

\subsection{Physical motivation (\tC{}) and its strict boundary}

The programme's geometric inspiration is T-duality in string theory. For a dimension
compactified on a circle of radius $R$, the free-boson partition function is invariant under
$R/\sqrt{\alpha'}\to\sqrt{\alpha'}/R$ with simultaneous exchange of momentum and winding
quantum numbers --- this is a genuine theorem about the CFT spectrum, established as
Eq.~(2.2.11) of \cite{giveon-porrati-rabinovici}. The fixed point of that map is
$R=\sqrt{\alpha'}$.

\begin{warnbox}{Boundary of the analogy --- Tier C, quarantined}
Reference \cite{giveon-porrati-rabinovici} was retrieved and read for this report, and the
distinction it forces is worth stating precisely, because the programme's earlier internal
documents blurred it. The \textbf{rigorous} content is the exact $R\leftrightarrow\alpha'/R$
symmetry of the spectrum. The frequently quoted claim that T-duality entails a
\textbf{``minimal length''} is a \emph{physical interpretation} of that symmetry --- the
argument being that a string cannot distinguish $R$ from $\alpha'/R$, so sub-$\sqrt{\alpha'}$
geometry is not resolvable --- and is \textbf{not itself a separately proved theorem} in the
sources consulted.

This report therefore uses T-duality \textbf{only} as motivation for the \emph{shape} of a
cutoff function. The mechanism acting on the PDE is the Fourier cutoff $J_{\sqrt{\alpha'}}$
and nothing more. Deriving the truncated dynamics from a genuine metric deformation is an
\emph{open problem} of this programme (OP-1), not an assumption. All cosmological
interpretation --- bounce scenarios, dark-sector mass laws, K3/mock-modular numerology --- is
quarantined in \texttt{docs/narrative/}, may never be imported by \texttt{lean\_src/}, and may
never be cited in a tier promotion.
\end{warnbox}

\Reff(\alpha,R) := \max\!\left(R,\ \frac{\alpha}{R}\right).
\end{equation}
The following are kernel-verified in \texttt{lean\_src/CallensDualScale.lean}, with axiom
footprint exactly \texttt{[propext, Classical.choice, Quot.sound]}:

These are theorems about the real-valued function $\max(R,\alpha/R)$. They are elementary,

language precisely; the parameter $\alpha'$ is carried as a \emph{hypothesis parameter}
($0<\alpha$), never as an axiom, because Hypothesis U itself quantifies over it. A prior
version of this repository asserted these as proven when no such proofs existed; that defect
and its correction are recorded in \texttt{LEDGER.md} under ``Retired / corrected claims''.
\end{keybox}

\subsection{The Symmetric-Square Lock (\tA{})}

The programme's second structural ingredient is an algebraic rigidity constraint. If a
sequence satisfies a second-order recurrence with operator $L_2$,
\[
u_{n+2}=a\,u_{n+1}+b\,u_n ,
\]
then $v_n := u_n^2$ satisfies the third-order recurrence
\begin{equation}
v_{n+3}=(a^2+b)\,v_{n+2}+b(a^2+b)\,v_{n+1}-b^3\,v_n ,
\label{eq:sym2}
\end{equation}
which is the symmetric square $L_3=\operatorname{Sym}^2(L_2)$. If $L_2$ has characteristic
roots $\{\lambda,\mu\}$, then $L_3$ has roots $\{\lambda^2,\lambda\mu,\mu^2\}$, and the
coefficients of \eqref{eq:sym2} are precisely their elementary symmetric functions:
\[
e_1=\lambda^2+\lambda\mu+\mu^2=a^2+b,\qquad
e_2=-b(a^2+b),\qquad
e_3=(\lambda\mu)^3=-b^3 .
\]
This spectral content is verified as \texttt{sym2\_symmetric\_functions} --- it is what makes
the identity \emph{structural} rather than a coincidence. The symmetric square of a
second-order operator being third-order is classical in the theory of linear differential
operators and Picard--Fuchs equations \cite{doran-sym2}.

\paragraph{Intended role (\tC{}).} The \emph{conjectural} purpose of the lock is to tie
macroscopic transport ($L_3$) rigidly to a microscopic fiber operator ($L_2$), so that
high-frequency modes cannot evolve as independent degrees of freedom --- the hoped-for
mechanism against Tao-type ``choreographed'' blow-up \cite{tao-averaged}. \textbf{Its
relevance to Navier--Stokes is a conjecture of this programme and is not established.} It
must be earned in the dyadic laboratory (\S\ref{sec:dyadic}).

\section{The ``Holographic Algebra'' Organising Concept}
\label{sec:holoalg}
%==============================================================================

\begin{warnbox}{Tier and status}
The name \emph{HoloAlg} (Holographic Algebra) denotes the programme's organising picture, not
a proven theory. \textbf{Everything in this section is \tC{}} except where it explicitly cites
a Tier A result from \S\ref{sec:tdual}. It is included because a reader must understand the
motivating picture to follow why the four tracks (\S\ref{sec:tracks}) were chosen --- not
because the picture carries evidential weight.
\end{warnbox}

\subsection{The picture}

The organising idea combines two elements already made precise:

\begin{enumerate}[leftmargin=*]
\item \textbf{A dual-scale geometry} in which the effective scale seen by the fluid is
$\Reff(\alpha',R)=\max(R,\alpha'/R)$, so that (i) macroscopic scales are unmodified
(\texttt{Reff\_inertial}: ``inertial invisibility''), and (ii) no scale below $\sqrt{\alpha'}$
is ever resolved (\texttt{Reff\_ge\_sqrt}). The regularisation is thereby confined strictly to
the sub-cutoff regime.
\item \textbf{An algebraic lock} (\S\ref{sec:tdual}) constraining macroscopic modes to be
generated by products of microscopic ones, restricting the admissible spectrum to
$\{\lambda^2,\lambda\mu,\mu^2\}$.
\end{enumerate}

The label ``holographic'' is used in the loose sense that macroscopic (bulk) transport is
determined by --- and rigidly constrained by --- data on a lower-dimensional algebraic
structure (the fiber operator's spectrum). \textbf{No claim is made of a relationship to the
AdS/CFT correspondence or any holographic duality in the technical sense of theoretical
physics.} No such correspondence has been constructed here, and none is used.

\subsection{Why this picture would matter, \emph{if} it could be substantiated}

For fluid mechanics, the mechanism would matter because it addresses obstruction O1
(Table~\ref{tab:obstructions}) with a \emph{structural} feature rather than an energetic one:
Tao's averaged system satisfies the energy identity yet blows up, so any successful strategy
must use something beyond energy. Algebraic rigidity of the mode spectrum is such a candidate.
For astrophysics and cosmology, the same cutoff geometry has been \emph{speculatively}
associated with bounce scenarios --- but that association is quarantined narrative, carries no
evidential weight here, and is deliberately excluded from the mathematical core.

\section{The Dyadic Shell Model: Established Results}
\label{sec:dyadic}
%==============================================================================

This section was written when the truncated dyadic shell model was the programme's
\emph{laboratory} --- a place to earn techniques before touching the continuum PDE. After the
audit of 13~August 2026 it is the programme's \emph{target} (\S\ref{sec:problem}). The results
below are unchanged by that reclassification; what changed is that they are no longer
preliminaries to something else. The model is due to Katz and Pavlovi\'c
\cite{katz-pavlovic}, whose published form (verified by retrieval, as restated in
\cite{cheskidov}) is
$\frac{d}{dt}u_n+\nu2^{2\alpha n}u_n-\lambda^nu_{n-1}^2+\lambda^{n+1}u_nu_{n+1}=g_n$.
The system used here is the unforced case with $\lambda^n$ playing the role of $k_n$: shells
$n=0,\dots,N$ carry wavenumbers $k_n=2^n$ and real amplitudes $a_n$, with
\begin{equation}
\frac{da_n}{dt}=\mathrm{NL}_n-\nu k_n^2 a_n,
\qquad
\mathrm{NL}_n := k_{n-1}a_{n-1}^2-k_na_na_{n+1},
\label{eq:shell}
\end{equation}
with truncation conventions $a_{-1}=0$, $a_{N+1}=0$. Energy is
$E=\tfrac12\sum a_n^2$ and enstrophy $\Omega=\tfrac12\sum k_n^2a_n^2$.

\begin{keybox}{Scope note (honesty clause)}
This model is \textbf{not} the Navier--Stokes equations. Its nonlinearity is \textbf{never}
asserted in this repository to be derived from, or to approximate, $(u\cdot\nabla)u$; the
audit of 13~August 2026 (\S\ref{sec:problem}) exists precisely because an earlier framing let
that boundary blur. Results below are exact statements about finite sums and their
consequences; no existence theory for the ODE system is invoked. What the model \emph{is} is a
well-studied object with a real literature and real open questions --- which is what makes it a
legitimate target rather than a proxy.
\end{keybox}

\subsection{Energy flux telescoping and monotonicity (\tA{})}

In \texttt{lean\_src/DyadicShells.lean}: the nonlinear energy flux telescopes for
\emph{arbitrary} $k$ and $a$ (\texttt{dyadic\_flux\_telescopes}); it vanishes under the
truncation $a_{N+1}=0$ (\texttt{dyadic\_flux\_zero\_of\_boundary}); and consequently
$dE/dt\le0$ for $\nu\ge0$ (\texttt{energyRate\_nonpos}). Non-vacuity is witnessed: a concrete
instance pins $dE/dt=-1$ exactly, so the inequality is not the trivial $0\le0$.

\subsection{The exact enstrophy-production identity (\tA{})}

The programme's most substantive dyadic result concerns \emph{enstrophy}, the quantity
Hypothesis U is about. Unlike energy flux, the enstrophy production sum does \emph{not}
telescope for arbitrary $k$; it collapses only under the doubling hypothesis
$k_{n+1}=2k_n$, and it collapses not to zero but to a multiple:

\begin{theorem}[Dyadic enstrophy production; \texttt{enstrophy\_production\_dyadic}]
Under $k_{n+1}=2k_n$ and truncation $a_{N+1}=0$,
\begin{equation}
\sum_{n=0}^{N} k_n^2 a_n \mathrm{NL}_n \;=\; 3\sum_{n<N} k_n^3a_n^2a_{n+1},
\end{equation}
so that the enstrophy evolves as
\begin{equation}
\frac{d\Omega}{dt} \;=\; 3\sum_{n} k_n^3a_n^2a_{n+1} \;-\; \nu\sum_n k_n^4a_n^2 .
\label{eq:production}
\end{equation}
\end{theorem}

This is the dyadic analogue of vortex stretching, made exact: a signed production term
competing against dissipation. The coefficient $3$ is not fitted --- it is $r^2-1$ for
doubling ratio $r=2$, and the Tier B harness independently confirms the general formula at
$r=3$ (coefficient $8$). A kernel-verified negative control
(\texttt{negative\_control\_nondoubling}) establishes that the identity genuinely \emph{fails}
for non-doubling $k$; the checker can fail.

\subsection{A local production bound (\tA{})}

Writing $S_N:=\sum_{n<N}k_n^3a_n^2a_{n+1}$ and $\Omega_N:=\tfrac12\sum_{n\le N}k_n^2a_n^2$,
\texttt{lean\_src/EnstrophyProductionBound.lean} proves, in a sqrt-free three-step chain
(elementary algebra, $\sum x^2\le(\sum x)^2$ for nonnegative $x$, Cauchy--Schwarz):
\begin{equation}
S_N^2 \;\le\; 2\,\Omega_N^3 .
\label{eq:bound}
\end{equation}

\begin{warnbox}{Precise scope of \eqref{eq:bound} --- this is where over-reading would be easy}
This is a \emph{local, instantaneous, algebraic} bound. It does \emph{not} use dissipation, it
does \emph{not} integrate in time, and it does \emph{not} address uniformity in $N$. Note the
exponent: production is bounded by $\Omega^{3/2}$, which is exactly the supercritical scaling
that makes the enstrophy differential inequality $\dot\Omega\lesssim\Omega^{3/2}$ insufficient
for global control. \textbf{Inequality \eqref{eq:bound} is therefore consistent with blow-up
and is not evidence for Hypothesis U.} It is infrastructure: an exact, reusable, verified
inequality, nothing more. The Tier B mirror further found, honestly, that the negative control
breaks Step 1 under non-doubling $k$ but does \emph{not} break the final bound on the tested
state family --- an unforced negative result, recorded.
\end{warnbox}

\section{Statement-Level Formalisation, the Pivot, and the Demotion}

\subsection{The shell-model Hypothesis U as a formal statement (\tA{}, \textsc{draft})}

\texttt{lean\_src/DyadicShell\_Statements.lean} (renamed 2026-08-13 from
\texttt{HypothesisU\_Statements.lean}, Memo Task 1) gives a non-vacuous Galerkin-shape
formalisation. Writing $u:\R\to(\N\to\R)$ for mode amplitudes, a solution at cutoff $N$
satisfies: (i) $u(0)=\mathrm{truncate}\,N\,u_0$; (ii) for every $t$ and every retained mode
$n\le N$, $\frac{d}{ds}u(s,n)|_{s=t}=B_n(u(t))-\nu w_n u(t,n)$; (iii) $u(t,n)=0$ for $n>N$.
Then
\begin{equation}
\mathrm{HypothesisU} \;:\equiv\;
\exists\,C>0.\ \forall N.\ \forall u.\ \bigl[\text{$u$ solves at cutoff $N$}\bigr]
\Rightarrow \forall t\in[0,T].\ \Omega_N(u,t)\le C .
\label{eq:formalU}
\end{equation}

\begin{keybox}{Why the quantifier order is the entire content}
$\exists C\,\forall N$ --- the constant is chosen \emph{before} the cutoff. Swapping to
$\forall N\,\exists C$ would be the trivial statement that each finite-dimensional truncation
is bounded on its own, which carries no information about the $\alpha'\to0$ limit. That swap
is the failure mode this ordering exists to exclude.
\end{keybox}

Two prior defects were repaired by explicit human decision (recorded as Q1, Q2): initial data
must be \emph{projected} per cutoff, else the hypothesis set is empty at low $N$ and the
statement holds vacuously; and the weight is fixed concretely to $w_n=(2^n)^2$, so that
``enstrophy'' is provably a nonnegative sum of squares rather than merely a name. The file
also \emph{machine-checks the refutation} of the prior formalisation: quantifying over all
smooth fields, without the equation as a constraint, yields a statement that is
\textbf{provably false} (\texttt{unconstrained\_bound\_false}), since scaling a field by $c$
scales enstrophy by $c^2$.

\subsection{Closing verdict A5: the nonlinearity is now concrete (\tA{})}

Until 13~August 2026 the mode-interaction term $B$ in \eqref{eq:formalU} was an
\textbf{abstract parameter}, and the previous version of this report named that the decisive
open item. The audit put it far more sharply (verdict A5): certifying a bound for an
unconstrained $B$ is a ``fatal flaw \ldots\ authenticating a mathematically empty envelope''
--- an arbitrary truncated sequence system simply blows up, so the envelope contains nothing.
Under the pivot this was repaired directly, by instantiating $B$ as the Katz--Pavlovi\'c shell
nonlinearity itself (Memo Task 2):
\begin{equation}
\texttt{shellB}:\quad
B_0(v)=-\bigl(k_0v_0v_1\bigr),\qquad
B_{m+1}(v)=k_mv_m^2-k_{m+1}v_{m+1}v_{m+2}.
\label{eq:shellB}
\end{equation}
The bottom shell has no influx, so $k_{-1}$ is never evaluated; for $n\ge1$ this is exactly
$\mathrm{NL}_n$ of \eqref{eq:shell}. The structural property whose absence the audit called
fatal is now a kernel-checked theorem, obtained from an exact telescoping identity:

\begin{theorem}[Shell energy pairing; \texttt{sum\_mul\_shellB}, \texttt{shellB\_energy\_conservation}]
For all $k,v:\N\to\R$ and all $N$, writing $\mathrm{out}_m:=k_mv_m^2v_{m+1}$, each summand
satisfies $v_nB_n(v)=\mathrm{out}_{n-1}-\mathrm{out}_n$ (reading $\mathrm{out}_{-1}=0$), so
that
\[
\sum_{n\le N} v_n\,B_n(v)\;=\;-\,k_Nv_N^2v_{N+1},
\qquad\text{and hence}\qquad
v_{N+1}=0\ \Longrightarrow\ \sum_{n\le N} v_n\,B_n(v)=0 .
\]
\end{theorem}

The truncation hypothesis $v_{N+1}=0$ is clause~(iii) of \texttt{IsGalerkinSolution}, so this
transfers to solutions with no extra assumption: \texttt{galerkin\_shellB\_conservation}
states that every Galerkin solution of the concrete model conserves energy exactly, at every
time. The viscous term of \texttt{IsGalerkinSolution} is $-\nu w_nu_n=-\nu k_n^2u_n$, which is
already the shell model's dissipation verbatim; together with \eqref{eq:shellB} this makes
\[
\texttt{DyadicShellHypothesisU}\;:\equiv\;\texttt{HypothesisU}\ \nu\ T\
\bigl(\texttt{shellB}\ k\bigr)\ \bigl(n\mapsto k_n^2\bigr)\ u_0
\]
the programme's headline statement, in which \textbf{nothing abstract remains}. It is a
statement about precisely the truncated viscous Katz--Pavlovi\'c system --- the same model
whose exact enstrophy-production identity is proven in \S\ref{sec:dyadic}.

\begin{warnbox}{What this does and does not fix}
It fixes A5, and only A5. \texttt{DyadicShellHypothesisU} is a \emph{statement}; it is not
proven, and nothing here is evidence that it is true. The abstract-$B$ scaffolding is retained
in the file solely because the refutation theorems and the inhabitation witnesses quantify over
it; it carries no headline claim. And instantiating $B$ with the \emph{true 3-D} nonlinearity
remains untouched and open --- that is OP-6 (\S\ref{sec:opsix}), now correctly labelled as the
3-D bridge rather than as this file's missing piece.
\end{warnbox}

\section{Numerical Investigation and Its Two Failures}
\label{sec:numerics}
%==============================================================================

The central empirical question is whether $\sup_t\Omega_N(t)$ grows with the cutoff $N$ or
saturates. Two successive designs \emph{failed their feasibility premises}, for genuinely
different reasons; both are documented rather than quietly replaced.

\begin{enumerate}[leftmargin=*]
\item \textbf{Explicit float RK4 (D4).} Stiffness: stability requires
$\Delta t\sim1/(\nu k_N^2)$, which collapses as $N$ grows. 21 of 36 configurations were
computationally infeasible.
\item \textbf{Exact-rational IMEX-Euler (D5).} The implicit viscous treatment removed the
stiffness barrier as designed --- but the scheme failed anyway, for an unrelated reason:
iterating a \emph{nonlinear} rational map in exact arithmetic causes the numerators and
denominators to grow geometrically in bit-length (hundreds of digits within 2--6 steps), while
the state magnitude stays small. \textbf{This is a representation blow-up, not a numerical
instability.} Implicit-versus-explicit was the wrong axis on which to redesign.
\end{enumerate}

\begin{keybox}{Generalised lesson, now a standing rule}
Exact rational arithmetic is excellent for closed-form algebraic identities and inequalities
proven in one shot, and poor for \emph{iterating} a nonlinear map over many steps. For
trajectories, use dual-precision floating point (Tier C steering) and reserve exactness for
the algebra. After two failed designs, the methodology decision was escalated to the human
owner rather than a third variant being chosen unilaterally.
\end{keybox}

\subsection{Resolution and the current evidence base (\tC{} steering data)}

The accepted resolution was to stop pursuing exact-rational certification and retain
dual-precision (float64 + 50-digit \texttt{mpmath}) runs as permanent Tier C steering data.
Across the full grid $N\in\{8,12,16,20,24\}$, several low-viscosity configurations initially
reported divergence, with the two precisions agreeing to $\sim10^{-14}$ --- ruling out
rounding, but \emph{not} distinguishing genuine divergence from an under-resolved step size
(the design's $\Delta t$ formula never depended on $\nu$). A step-size refinement study
resolved this:

\begin{center}
\begin{tabular}{@{}lp{11.6cm}@{}}
\toprule
\textbf{Finding} & \textbf{Detail} \\
\midrule
Divergences are artifacts & All four diverging $(\nu,\text{profile})$ pairs flip to \texttt{OK} at a finite refinement level and stay \texttt{OK} at every finer level, with $\sup\Omega$ \emph{decreasing} as $\Delta t\to0$ (e.g.\ $45.1\to21.8\to17.3\to15.8$) --- the signature of a discretisation artifact resolving, not a fixed-time blow-up. \\
\addlinespace
$N$-independence & 44 of 45 configurations are \emph{exactly} flat in $N$ (bit-identical $\sup\Omega$ at every cutoff). \textbf{This was reported as striking evidence. It is not evidence at all --- see the retraction immediately below.} \\
\addlinespace
The one exception, explained & $\nu=0.1$, profile P2 appeared to grow linearly in $N$ ($4.5,6.5,\dots,12.5$). Traced by hand: this equals $\tfrac12(N+1)$, which is profile P2's \emph{analytic initial} enstrophy --- P2 excites every retained mode by construction, so a larger cutoff starts with more enstrophy independent of any dynamics. The trajectory collapses immediately from $t=0$ and decays thereafter. \textbf{An initial-data artifact, not dynamical growth.} \\

\end{center}

\begin{warnbox}{Retraction (14 August 2026): the $N$-flatness is an artifact of the grid}
An earlier version of this report presented the flatness above as the evidence base for a
uniformity verdict. \textbf{That reading was wrong, and the error was the report's own.} Direct
measurement of the shell-amplitude profile shows the cascade never reaches the shells the grid
varies. At $\nu=10^{-3}$ the enstrophy is carried almost entirely by a \emph{single} shell:

\begin{center}
\small

\toprule

The grid's \emph{smallest} cutoff was $N=8$ --- exactly one shell above the decisive one. Raising

``Flat in $N$'' is therefore close to a tautology here and cannot distinguish
\emph{``the bound is uniform in the cutoff''} from \emph{``no regime was tested in which the
cutoff binds''}. No verdict may be issued on this evidence base, and none has been.

\begin{keybox}{The failure mode is now mechanically excluded}
A Tier B harness (\texttt{tests/tier\_b\_grid\_adequacy.py}, wired into Gate~1) rejects such a

rates with the K41 amplitude $a_n\sim k_n^{-1/3}$ gives $k_d\sim\nu^{-3/4}$; with $k_n=2^n$ the
cutoff lies at or above the dissipation scale iff $2^{4N}\nu^3\ge1$, i.e.\ writing $\nu=p/q$,
iff the integer inequality $2^{4N}p^3\ge q^3$ holds. No floats, no logarithms.

Its negative control is the historical grid itself: \textbf{0 of 15 configurations had a biting
cutoff}. The redesigned measurement (\texttt{docs/designs/D6\_CUTOFF\_BITING\_MEASUREMENT.md})
sweeps $N$ \emph{across} the dissipation shell instead of above it, reports the production flux
at the cutoff and the shell-population profile alongside $\sup\Omega$, and carries a $\nu=0$
control where blow-up is a published theorem --- the sharper control, because it is the one this
programme's hoped-for conclusion would predict wrongly.
\end{keybox}

\section{The 3-D Bridge: Instantiating the True Nonlinearity (OP-6)}
\label{sec:opsix}
%==============================================================================

This section describes work aimed at the \emph{true} 3-D nonlinearity. It should now be read
as work on the \textbf{bridge} between the programme's formal target (the shell model,
\S\ref{sec:dyadic}, \S\ref{sec:audit}) and its motivating problem (\S\ref{sec:problem}) ---
open future work, and not a claim that the bridge exists. Note the distinction from
\S\ref{sec:audit}: $B$ in \eqref{eq:formalU} is no longer abstract, having been instantiated
by the shell nonlinearity \eqref{eq:shellB}; what remains open is instantiating it by the
Fourier--Galerkin nonlinearity on $\Z^3$, which is a different and strictly harder object.

A repository-wide search established that \textbf{no Fourier-triad convolution
formula exists anywhere in this programme's sanctioned content} --- the triad tooling counts
lattice points without amplitudes; the OP-2 draft self-admits it discards the angular
structure of $k$ ``which is precisely where 3-D vortex-stretching geometry lives''; and the
dyadic $\mathrm{NL}_n$ is never asserted to derive from $(u\cdot\nabla)u$. Instantiating $B$
by the 3-D nonlinearity is therefore a genuine E-1 blocker.

On $\T^3$, with $u=\sum_k\hat u_ke^{ik\cdot x}$, $k\cdot\hat u_k=0$,
$\hat u_{-k}=\overline{\hat u_k}$, and Leray projector
$P(k)=I-\frac{k\otimes k}{|k|^2}$, the truncated nonlinearity is
\begin{equation}
\partial_t\hat u_k = -\nu|k|^2\hat u_k
- i\!\!\sum_{\substack{p+q=k\\ p,q\in\Lambda}}\!\! P(k)\bigl[(q\cdot\hat u_p)\,\hat u_q\bigr].
\label{eq:fourier}
\end{equation}

\begin{keybox}{An erratum caught by exact arithmetic --- a case study in why the method exists}
The formula first recorded in the scoping memo, taken from a single literature cross-check,
read $P(k)[q\,(\hat u_p\cdot\hat u_q)]$ --- the \emph{vector} $q$ times the scalar
velocity--velocity dot product. The Tier B harness then \emph{proved}, in exact arithmetic,
that this expression is \textbf{identically zero for every $k$}: $P(k)$ annihilates anything
parallel to $k$, and since every pair $(p,q)$ with $p+q=k$ appears alongside its swap
$(q,p)$, the two terms cancel exactly,
$P(k)[q s]+P(k)[p s]=P(k)[(p+q)s]=P(k)[k s]=0$. That cannot be the real nonlinearity. The
corrected form \eqref{eq:fourier} --- $q$ \emph{dotted} with $\hat u_p$, a scalar, times the
vector $\hat u_q$ --- matches the Fourier transform of the convective derivative and is
nonzero. The error was caught by computation, not by inspection.
\end{keybox}

The resulting harness (\texttt{tests/tier\_b\_nse\_triad\_convolution.py}, \tB{}) certifies
two structural facts in exact Gaussian-rational arithmetic at $M=1,2,3$:
\emph{transversality} $k\cdot N(u)_k=0$ (unconditional, since $P(k)$ projects onto $k^\perp$),
and \emph{detailed energy conservation} $\sum_k\overline{\hat u_k}\cdot N(u)_k=0$ given
divergence-free, conjugate-symmetric input. Two negative controls --- dropping the Leray
projection, and breaking the divergence-free condition on one mode --- each break exactly one
fact and leave the other intact, matching the hand derivation rather than merely
``changing something''.

\begin{keybox}{Recorded honestly: several negative controls were undetectable by construction}
Two natural ``plausible bug'' perturbations turned out to be invisible: swapping $p\leftrightarrow q$
throughout (the pair set is symmetric under relabelling for \emph{every} fixed $k$, not merely
after summing), and substituting the outer $k$ for the summed $q$ (the difference vanishes
because $p\cdot\hat u_p=0$ by divergence-freeness). The negative control actually used ---
multiplying by the wrong velocity factor --- was found by \emph{testing} candidates, not by
assuming one would work. Additionally, the general triad identity underlying energy
conservation is here verified \emph{computationally} at three truncations, \textbf{not proven
symbolically}; a Tier A proof remains future work.
\end{keybox}

\subsection{From computational check to kernel proof (\tA{})}

The harness above certifies two facts \emph{computationally}, at three truncations, and its own
docstring declines to claim either as proven. Both are now Tier A, in
\texttt{lean\_src/AbstractAlgebraicConservation.lean} --- renamed 2026-08-13 from
\texttt{TriadConservation.lean} under audit verdict C1, which found the old name
\textsc{overstates reach}: the file's abstraction bypasses geometric aliasing on $\Z^3$
entirely, and the name should say so. The docstring now states that exclusion explicitly:

\begin{theorem}[Termwise triad cancellation; \texttt{triad\_pairing}]
If $k_p+k_q+k_r=0$ componentwise and the field is divergence-free at $p$
($k_p\cdot u_p=0$), then the two orderings of the triad summand cancel \emph{exactly}:
\[
(k_q\cdot u_p)(u_q\cdot u_r)\;+\;(k_r\cdot u_p)(u_r\cdot u_q)\;=\;0 .
\]
\end{theorem}

\begin{keybox}{Why the first attempt failed, and what actually worked}
The harness records that a direct \emph{three-way} relabelling (cycling $p\to q\to r$) did not
close. It does not need to. The cancellation is \textbf{two-way}, and stronger than a summation
argument: it is \textbf{termwise}. Pairing $(p,q,r)$ with $(p,r,q)$ --- swapping only the last
two indices, leaving $p$ fixed --- and using symmetry of the pairing followed by additivity,
\[
\bigl[(k_q\cdot u_p)+(k_r\cdot u_p)\bigr](u_q\cdot u_r)
=\bigl((k_q+k_r)\cdot u_p\bigr)(u_q\cdot u_r)
=\bigl(-k_p\cdot u_p\bigr)(u_q\cdot u_r)=0 .
\]
This was re-derived by hand and confirmed on 6486 triples in exact arithmetic \emph{before} any
Lean was written. Summing it over any finite index set closed under the swap gives detailed
energy conservation (\texttt{triad\_sum\_zero}); transversality
(\texttt{transversality\_of\_sum}) is separate and unconditional, following from the projector
landing in $k^\perp$.
\end{keybox}

\begin{warnbox}{Scope: this does not close OP-6}
The file is stated over an \emph{arbitrary commutative ring}, with an arbitrary additive index
group and additive wavevector map. It is deliberately \textbf{not} stated over
$\Lambda\subset\Z^3$ with complex velocities, because that concrete apparatus \emph{is} the open
decision D1. \textbf{The bridge from this lemma to the concrete Fourier--Galerkin setting is not
built}; nothing here instantiates $B$; nothing here is a statement about Navier--Stokes
solutions. One hypothesis is load-bearing rather than technical: the swap has fixed points
(where $q=r$, forcing $p=-2q$) at which the pairing yields only $2f=0$, so the ring must have no
2-torsion. For the intended instantiations ($\R$, $\C$) this holds.
\end{warnbox}

\paragraph{Open decisions.} Instantiating $B$ is not a substitution but a restructuring: the
state representation must move from $\N\to\R$ shell scalars to $\Z^3\to\C^3$ Fourier vectors
carrying divergence-free and reality constraints. Whether to undertake that full reindexing or
seek a smaller shell-preserving proxy, and whether to sequence it before or after OP-2,
are open questions reserved to the human owner.

%==============================================================================
\begin{warnbox}{A second, sharper limit on the pivot (14 August 2026)}
The audit established that the formalisation describes a shell model rather than 3-D
Navier--Stokes. A further fact bounds what the shell model can deliver even in principle.

The dyadic dissipation term is $\nu k_n^{2\alpha}$; the Navier--Stokes viscous term is
$\nu\Delta u$, whose Fourier symbol is $-\nu|k|^2$. Hence $\alpha=1$ \emph{is} the
Navier--Stokes dissipation --- the same exponent, not an analogy. Cheskidov proves global
regularity for $\alpha\ge1/2$. Therefore:

\begin{center}
\textbf{The dyadic shell model at Navier--Stokes dissipation is provably regular.}
\end{center}

The model's difficult regime, $\alpha<1/2$, corresponds to dissipation \emph{weaker} than
Navier--Stokes. A result in the open band $[1/3,1/2)$ is a result about \emph{hypo-dissipative}
shell models. That is live mathematics --- the band is open, and Cheskidov singles out
$\alpha=1/3$ as carrying the same nonlinear estimates as 4-D Navier--Stokes --- but it is
\textbf{not a step toward 3-D Navier--Stokes and must never be reported as one}.

An unplanned consistency check fell out of the same calculation. The K41 balance
$\nu k^{2\alpha}\sim k\,a_k$ with $a_k\sim k^{-1/3}$ gives a dissipation scale
$k_d\sim\nu^{-1/(2\alpha-2/3)}$, whose exponent \emph{diverges} as $\alpha\to1/3^+$: below that
threshold no dissipation scale exists, so the cascade is stopped at no finite shell. That is
exactly Cheskidov's proven blow-up threshold, reached from an elementary heuristic that knows
nothing of his proof.

\textbf{Owner decision:} this gap is to be treated as a gap to \emph{close}, not a ceiling to
accept. The programme will pursue the bridge --- the $\Z^3$ embedding and the instantiation of
the nonlinearity --- both of which remain blocked on definitions that do not exist, and so
admit only authored candidates submitted for human audit.
\end{warnbox}

\subsection{Repairing the reduction: giving the hypotheses content (\tC{})}

Audit verdict~B1 found the reduction's two hypothesis parameters to be bare
$\mathrm{Prop}\to\mathrm{Prop}$ arrows: ``the Lean kernel is merely verifying a logical
tautology''. The repair, carried out on 14~August 2026, is \emph{not} to prove those steps ---
parking undischarged analysis in a named hypothesis parameter rather than an axiom is the
pattern this programme deliberately adopted, so that the kernel tracks the debt in the type. The
repair is to make the types say something.

\begin{keybox}{What a compactness statement has to deliver}
\texttt{IsGalerkinLimit} now carries four clauses, each load-bearing: the limit solves the
untruncated system; it has \emph{finite enstrophy} (a genuine $\ell^2$ condition, since there is
no cutoff to truncate the sum); that enstrophy is bounded on every horizon, with the constant
quantified \emph{inside} the horizon --- compactness gives no uniformity in $T$, and writing
$\exists C\,\forall T$ would claim more than the analysis provides; and the limit is genuinely
the modewise limit of the Galerkin family \textbf{along a subsequence}. The subsequence is not a
technicality: a compactness argument extracts one, and asserting convergence of the full
sequence would overstate the mathematics.
\end{keybox}

The $\ell^2$ upgrade was deliberately \emph{localised}. Hypothesis~U quantifies over
\emph{Galerkin} solutions, whose truncation clause forces $u_n=0$ for $n>N$ --- so the finite
sum over $n \le N$ already captures every nonzero mode and is \emph{exact} there, not an
approximation. Only the objects with no cutoff needed the infinite-series treatment. A bridge
lemma (bounded partial sums of nonnegative terms $\iff$ summable with $\sum' \le C$) makes the
upgrade a conservative extension: nothing previously proven is invalidated.

\begin{warnbox}{The file remains Tier C, and two things remain unmachine-checkable}
The repair makes the undischarged debt \emph{legible}; it does not pay it. Both hypothesis
parameters are still assumed. Moreover, whether the four clauses \emph{say the right thing} is a
statement-adequacy question reserved to human audit --- it cannot be settled by the kernel, and
that cost is scheduled rather than discovered later.
\end{warnbox}

\subsection{Eliminating a duplication hazard at the root}

Until this point every file in \texttt{lean\_src/} re-declared, verbatim, the definitions it
needed from its neighbours, because the verification gate compiled each file in isolation and
cross-file imports did not resolve. That convention carried a silent-drift hazard of exactly the
kind this programme exists to eliminate: \textbf{a correction applied to one copy and not the
other leaves both files compiling cleanly, both gates green, and the mathematics divergent}, with
no mechanism able to see it.

With the project now self-contained, the gate builds the dependency graph first and then
re-elaborates each file with the project's own build directory on the search path. Imports
resolve; the duplication is gone; there is exactly one definition of each object in the
repository. One implementation detail is worth recording because getting it wrong would be
invisible: the gate must re-elaborate with \texttt{lean} rather than rely on \texttt{lake build}
alone, because a \emph{cached} build target emits no axiom output at all --- which would make the
footprint check silently vacuous rather than failing loudly.
