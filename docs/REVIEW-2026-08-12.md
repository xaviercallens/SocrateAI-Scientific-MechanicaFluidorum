# Critical Review of Specification v0.1 — 2026-08-12

Reviewed: `SPEC_v0.1_original.md` (the received spec) and the prior formalization tree at
`~/xdev/SocrateAI-Scientific-RajMathRecovery/dualscale/lean/` (audited in full).
The review applies the spec's **own** standards (§5.1–§5.5) to the spec itself.

## Verdict

The engineering skeleton — three-tier gating, verifier-in-the-loop, human-audits-the-question,
counterexample-before-attack, non-vacuity checks — is genuinely strong and worth keeping intact.
The mathematical content contains one real, verified nugget (`sym2_recurrence`) and one correct
but **standard** reduction (Proposition 5.1). However, the spec **overstates its verified status**
(it claims Tier A theorems that existed nowhere), **understates the difficulty of Hypothesis U**
(which is a restatement of the Millennium problem, not a reduction of it), and its own embedded
foundation file **violates three of its own five rules**. Every defect below is repairable, and
the most concrete ones were repaired today (§E).

The most encouraging meta-finding: the spec's rules §5.1–§5.5 are exactly the rules its own
artifacts break. The rules are right. The enforcement was missing. v0.2 adds the enforcement.

## B. Mathematical findings (must-fix in framing, not in logic)

**M1 — Hypothesis U is a restatement, not a reduction.**
The "T-dual regularized system" with projection `J_{√α'}` onto frequencies |k| ≤ 1/√α' *is* the
classical Leray/Fourier–Galerkin mollification (Leray 1934; standard in every graduate text).
That mollified systems are globally smooth, and that a **uniform-in-cutoff enstrophy bound**
implies regularity of the limit, is classical. Uniform enstrophy control **is the open heart of
the Millennium problem**: nothing has been made easier; the problem has been given one clean
quantitative target. That is genuinely useful for organizing an attack — but v0.2 must say
"restatement/reformulation", never "reduction of difficulty". Overselling this is precisely the
"historical pitfall" §1 warns about.

**M2 — The spec engages zero known obstructions. v0.2 adds a mandatory Obstruction Ledger.**
Any credible strategy document for this problem must state how it evades:
- **Tao (2016), averaged Navier–Stokes blowup**: there is a modification of the NSE nonlinearity
  obeying the same energy identity whose solutions blow up in finite time. Consequence: no
  argument using only the energy identity plus abstract functional analysis can prove
  Hypothesis U. Each track must identify the *specific structural feature* of the true
  nonlinearity it exploits.
- **Supercriticality**: enstrophy is supercritical under NSE scaling; the vortex-stretching
  term ∫ω·S·ω is exactly what all known methods fail to control. The cutoff J_{√α'} does not
  weaken vortex stretching at frequencies below the cutoff — uniformity in α' is the whole game.
- **CKN partial regularity (Caffarelli–Kohn–Nirenberg 1982)**: best known bound — the singular
  set has 1-dimensional parabolic Hausdorff measure zero. The Duminil-Copin track's target
  ("Hausdorff dimension strictly zero") *exceeds the world state of the art*; it needs a
  proportionally extraordinary mechanism, stated as a conjecture with a falsification plan.
- **Non-uniqueness of weak solutions (Buckmaster–Vicol 2019)**: weak-limit arguments must track
  in which class the limit is unique; "a subsequence converges to a Leray–Hopf solution" does
  not by itself select the physical solution.
- **The Euler test**: the regularization and the energy identity survive ν → 0, but global
  regularity for 3D Euler from smooth data is expected false (and blowup is proven for boundary
  and self-similar scenarios). Any proposed proof of Hypothesis U that nowhere uses ν > 0 is
  presumptively wrong. This is a cheap, powerful sanity filter for agent-generated strategies.

**M3 — The T-dual metric and the PDE are currently disconnected.**
The four Reff theorems are true (now actually proven), but they are statements about the
function max(R, α/R) — the regularized PDE never uses `Reff`; it only uses the sharp Fourier
cutoff. Either (a) derive the cutoff dynamics from the effective metric (a real research task,
Tier C), or (b) present Reff honestly as the *inspiration* and the cutoff as the *mechanism*.
v0.2 adopts (b) and files (a) as an open problem.

**M4 — The four tracks are Tier C analogies and must be labeled and managed as such.**
Per-track concerns each must answer before any formal work (§5.3):
- *Bourgain–Demeter*: triadic resonances k₁+k₂=k₃ on ℤ³ are abundant (the resonant set of a
  frequency pair is a full lattice set, not a thin arithmetic one). "Statistical starvation"
  must be a quantitative decoupling statement that beats this abundance; also ℓ²-decoupling
  controls *linear* extension operators — transferring it to a quadratic cascade term is
  itself an open step.
- *Villani–Mouhot*: Landau damping lives in collisionless transport with a confining mechanism
  and Gevrey data; the NSE cascade is dissipative and supercritical. The Gevrey–Newton scheme
  is a plausible *tool*, but there is no known analogue result; the "enstrophy echo" must first
  be *defined* precisely.
- *Golse–Saint-Raymond*: α' → 0 is not a Knudsen limit — there is no kinetic layer under the
  truncated system. Either introduce a genuine kinetic model whose hydrodynamic limit is the
  truncated NSE (heavy, reopens Hilbert-6th-scale issues) or re-found this track as a
  relative-entropy/renormalization method applied directly at PDE level (DiPerna–Lions style).
- *Duminil-Copin*: must beat CKN (see M2). First falsifiable milestone: reproduce CKN's
  dimension bound in the lattice formulation; kill the track if the lattice formulation cannot
  even recover the known result.

**M5 — Claimed-but-nonexistent theorems.**
§2.1 asserts the four Reff theorems are "proven in Lean with zero custom axioms". A full grep
of every prior tree found **no occurrence of `Reff` anywhere**. This is the exact failure mode
the tier system exists to catch: a Tier C claim wearing Tier A clothes. Repaired today — the
four theorems (plus positivity) are now actually proven; see §E.

## C. Lean audit — file-level defects (evidence-based)

**L1 — The spec's own foundation file violates §5.1.** `axiom alpha_prime : ℝ` and
`axiom alpha_prime_pos` are custom axioms. Consequently the spec's "expected" gate output
`[propext, Classical.choice, Quot.sound]` for `genesis_no_singularity` is **impossible as
written** — the true output would include both custom axioms. Fix (done): α' enters every
statement as an explicit hypothesis `(hα : 0 < α)`.

**L2 — Type error.** `MacroManifold.lattice_det : ℤ` is a constant, yet `resonance_law`
applies it to a point (`lattice_det m`). The file cannot compile. Fix (done): `lattice_det : M → ℤ`.

**L3 — Vacuous Hypothesis U in the prior tree** (`NS/HypothesisU.lean`). `TruncatedFlow a` is
defined as *an arbitrary smooth vector field* — no Navier–Stokes equation, no initial datum, no
dependence on `a`. The formalized `HypothesisU` therefore quantifies over ALL smooth fields and
is **provably false** (scale any field by λ: enstrophy scales by λ², unbounded), making the
downstream lemma `compactness_step_is_open` vacuous. A §5.5 failure in production. The honest
formalization must constrain `u` to solve the Galerkin system with fixed initial data.

**L4 — Junk-value trap (integrals).** §5.1 correctly flags `x/0 = 0`; the same trap applies to
`MeasureTheory.integral`, which returns 0 for non-integrable functions. `enstrophyDensity`
integrates over ℝ³ without an integrability side condition, so "enstrophy ≤ C" can hold because
the integral silently evaluated to 0. New rule in v0.2 §7: every division and every integral in
a Tier A statement needs a witnessed side condition.

**L5 — Numerology inside the mathematical core.** `CentralCharge := ℝ` with magic constants
(0.4141, 0.6667, 1.7) and `bps_scaling` if-chains multiply the enstrophy by an inert positive
weight. Mathematically irrelevant, physically undefended, and it contaminates the definition
of Hypothesis U itself. v0.2 quarantines all physics narrative (K3, cosmology, dark sector)
into `docs/narrative/`, which `lean_src/` may never import or cite in tier promotions.

**L6 — Trivial-witness "well-posedness"** (`NS/DyadicShell.lean`). The theorem
`global_well_posedness_regularized_shell` proves `∃ u, IsRegularizedSolution u` — satisfied by
`u ≡ 0`. It carries a "Tier A" label while establishing nothing about the cascade. Statements
must quantify over initial data: *for every* initial state there exists a global solution.

**L7 — Raw axiom** (`NS/AubinLions.lean`): `axiom aubin_lions_compactness`. Honestly documented,
but §5.1 bans it, and an axiom whose statement contains a defective definition (L3) is doubly
dangerous. v0.2 style: make unproven infrastructure an explicit *hypothesis parameter* of the
theorems that need it (`theorem limit_regular (hAL : AubinLionsStatement) : …`), so the kernel
tracks the debt in the type, not in the axiom environment.

**L8 — Version proliferation** in the prior tree (dozens of `Discovery/verify_*.lean`,
`targets/Candidate_*.lean`) — exactly what §5.4 bans. The new repo starts clean; the ban is
now enforceable by CI file-listing.

**L9 — Toolchain pin.** Spec says "lean4/v4.22.0 & Mathlib v4.22.0" (Mathlib does not version
that way). Environment reality: Lean v4.33.0-rc2 with a fully built 4.8 GB Mathlib available
locally. v0.2 pins `leanprover/lean4:v4.33.0-rc2` to reuse the verified build; migration to a
stable tag is a Stage-0 chore.

## D. Engineering findings

**E1 — SCSC.** For open-problem work there is no gold reference, so D1/D2 are undefined; the
formula silently degenerates. Worse, TE1 (LLM judge of statement adequacy) is the weakest link
and must **never** gate a tier promotion — statement adequacy is exactly the part the *human*
audits under the declared oversight paradigm. v0.2: SCSC = (IC1 · IC2)^(1/2) as the mechanical
score; TE1 becomes an advisory flag that *requests human audit*; D1/D2 apply only to benchmark
exercises where a gold exists.

**E2 — `gfun` is a Maple package**, not Python. Production guessing should use SageMath's
`ore_algebra` or Maple `gfun`; the repo now ships an exact-ℚ guess-and-prove core
(`symbolic/picard_fuchs_generator.py`) sufficient for the current stage, with a working
negative control (u³ is refused at order 3 and verified at order 4 — matching Sym³ theory).

**E3 — `rns_multiplier_test.py`** (residue-number-system multiplier?) has no connection to any
stated goal; replaced by `tests/tier_b_exact_checks.py` (checks B1–B4, all exact, zero floats).
